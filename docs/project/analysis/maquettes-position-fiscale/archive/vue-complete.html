Comment lire, de gauche à droite : ce que chaque appartement rapporte → le résultat de l'entité → dans quelle tirelire il tombe. Les années d'achat (2021, 2024) remplissent le déficit ; les années de croisière (2022, 2023, 2026) remplissent les amortissements. En 2023, la tirelire amort baisse de 4 077 : c'est le choix du comptable d'imputer le bénéfice sur l'amortissement (l'app aurait baissé le déficit à la place). Valeurs des tirelires = officielles ; le détail par appartement = calcul de l'app (seule source qui ventile). Ligne reprise = point de départ pour 2026.
