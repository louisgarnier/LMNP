L'essentiel : le total à déduire est quasi identique (~75-76 k€, écart ~1 200 €). La vraie différence, c'est la répartition : le comptable a mis plus dans le déficit (39 913) et moins dans les amortissements, l'application l'inverse. Le déficit expire en 10 ans, pas les amortissements — donc en garder plus dans le déficit (choix comptable) est légèrement plus risqué, mais l'enjeu est faible tant que tu redeviens bénéficiaire avant 2031.
